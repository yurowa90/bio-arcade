# 결정 기록 (Decision Log)

이 저장소에서 내린 결정을 기록한 순서대로 번호를 매겨 적는다(나중에 기록한 결정은 날짜가 앞설 수 있다). 코드와 커밋은 '무엇을 바꿨는지'를 남기지만, '왜 그렇게 정했고 무엇을 버렸는지'는 여기에만 남는다.

## 쓰는 법

- 결정을 내리면 그 자리에서 맨 아래에 다음 번호로 추가한다. 나중에 몰아 쓰면 근거를 잃는다. 번호는 다시 쓰지 않는다.
- 새 항목을 쓰면 색인 표에도 한 줄 넣는다. 색인의 '결정' 칸과 본문 제목은 같은 문구로 쓴다.
- 이전 결정을 뒤집기 전에 사용자에게 근거를 들어 확인한다. 뒤집을 때는 원래 항목을 지우지 않고 상태를 `대체됨(D-0NN)`으로 바꾼 뒤 새 항목을 쓴다.
- 근거가 기록에서 확인되지 않고 추론한 것이면 `(추정)`이라고 적는다.
- 교사의 판단을 기다리는 일은 결정이 아니므로 `docs/PROGRESS.md`의 미결 사항(M번호)에 둔다. 진행 문서의 항목은 T·M 고정 번호로 가리킨다.

항목 형식:

```
### D-0NN 제목
- 날짜 · 상태: YYYY-MM-DD · 채택 | 대체됨(D-0NN) | 철회
- 맥락: 무엇이 문제였나
- 결정: 무엇으로 정했나
- 근거: 왜 그렇게 정했나(검증 수치가 있으면 함께)
- 검토한 대안: 버린 안과 버린 까닭
- 영향: 바뀌는 파일·테스트, 뒤따라 지켜야 할 것
- 관련: 커밋, 파일, 문서
```

### D-005 광합성 기공 전환 무료, 별 6·9·12
- 날짜 · 상태: 2026-10-02 · 채택
- 맥락: 별 3 칭찬은 '밤에 기공을 닫아 물을 아꼈다'인데, 실제 규칙에서는 밤에도 기공을 열어 두는 쪽이 유리했다(밤 열림 최대 녹말 11, 닫힘 9). 닫았다 다시 여는 데 행동 두 번이 들고, 열어 둘 때 손해는 물 1뿐이었다.
- 결정: 기공 열기·닫기는 턴을 쓰지 않는다. 가뭄 동안 물 흡수는 0, 처음 물은 3, 별 기준은 녹말 6·9·12(승리 6). 별 3 칭찬은 밤 턴에 기공이 실제로 닫혔을 때만 나온다.
- 근거: 전수 탐색(6^10 수열)에서 밤에 연 수열의 최대 녹말은 11로 별 3 기준 12에 못 미치고, 밤에 닫으면 13까지 간다. 마구 눌러 이길 확률은 1.99%.
- 검토한 대안: 밤 손실 +1·+2, 새벽 자동 열림. 열림·닫힘 격차가 0~1이거나 생물학적 근거가 약해 버렸다.
- 영향: `tests/quest-logic.js`에 '밤에 연 수열 최대 < 별 3 기준' 단언. 규칙을 바꾸면 `node tests/quest-tune-photo.js`로 다시 확인한다.
- 관련: 5c38040, `games/quest/js/battles.js`

### D-044 별 기준과 마지막 바퀴 형식: 까닭이 별 2의 문, 섞은 4지, 경계 문항
- 날짜 · 상태: 2026-10-03 · 채택(교사 결정, 설계안 결정 4·7·8)
- 맥락: 별은 마지막 '불 꺼진 바퀴'의 12문항(지나는 곳 이름 8개, 대동맥·대정맥·폐동맥·폐정맥을 「동맥」·「정맥」이라고 부르는 까닭 4개)으로 정한다. 재검토에서 같은 종류 4지 형식이 경로 구조를 미리 알려 주고(F3), 두 순환의 시작과 끝을 묻지 않는다(F5)는 지적이 나왔다.

- 검토한 대안: 경로(이름 8개)를 별 2의 문으로 하는 안, 별 1 문턱을 이름 4개로 낮추는 안, 같은 종류 4지 유지, 경계 문항 없이 서술 답으로만 보는 안.
- 영향: 섞은 4지로 바꾸므로 전략별 별을 구현 때 다시 계산해 이 항목의 근거와 Node 단언에 남긴다(완료, 690a22c). 섞은 4지의 구성, 버튼 순서, 혈관 자리에 심장 방을 고른 경우의 오개념 꼬리표도 구현 때 정한다.

### D-052 루미큐브 줄은 ‘이룬다’ 관계표로 판정(색은 계 표시), 묶음에 같은 이름 패 금지·개체 생물 추가

### D-055 루미큐브 설계 GPT 검토 반영: 용어(물관을 이루는 세포), 옥수수→토마토, 완전한 줄을 별 조건에, 줄 전체 제약 보강

  - 지적 1(high, 줄 전체 제약): 관계표에 심장 근육 세포→근육 조직과 근육 조직→위가 모두 있어 '심장 근육 세포 → 근육 조직 → 위'가 줄이 된다. 근육 조직→위 자체는 참이지만 위의 운동을 맡는 것은 민무늬근이고 심장 근육 세포가 아니다.
  - 지적 2(high, 줄 전체 제약): 울타리 조직을 이룬 줄의 기관을 잎으로 제한해도 '울타리 조직 → 기본 조직계 → 잎 → 옥수수'는 걸러지지 않는다. 옥수수(외떡잎식물)의 잎은 울타리 조직과 해면 조직으로 나뉘지 않는다.
  - 지적 3(medium, 오개념 신호): relationError의 대표 사례로 든 '신경 조직 → 심장'은 실제로 참이다(심장에도 신경 섬유가 있다). '신경 조직 → 위'도 참이며 설계의 단순화 설명이 이미 이를 인정한다. 대표 연결만 허용하는 규칙과 '과학적으로 틀린 연결'의 진단은 다르다.
  - 지적 4(medium, 규칙과 개념, 교사 판단 필요): 상피 세포 → 상피 조직 → 위는 기관계 없이도 줄이어서 '동물 줄에 기관계를 넣어야만 줄이 된다'는 서술이 사실이 아니다. 서로 다른 세포 5장·조직 5장·개체 4장인 14장은 묶음 세 개로 한 턴에 비울 수 있어, 동물·식물의 구성 단계를 비교하지 않고도 최고 별을 받는다.
  - 검토는 단계 순서와 묶음 기준, 공변세포의 표피 소속과 줄기의 기공을 타당하다고 보았고, 물관을 조직으로 두는 것을 오류로 볼 근거는 없다고 했다. '물관 세포' 같은 출판사별 표기는 확인하지 못했고(M9), 교과서 PDF 시각 대조는 실패했으며, 실제 게임 검사와 별 분포 시뮬레이션은 하지 않았다(규칙 모듈이 아직 없다). 지적 1·2는 관계표를 열거해 두 줄이 허용됨을 다시 확인했다. Astra의 Node 반례 검사 결과는 재실행하지 않은 주장으로 둔다.
- 결정: 교사 결정 세 가지와 총괄 판단 세 가지다.
  - 교사 ① (M9): 패 용어는 그대로 쓰되 '물관 세포'만 '물관을 이루는 세포'로 바꾼다. 공변세포를 표피 조직의 세포로 두는 것도 그대로다.
  - 교사 ②: 식물 개체 '옥수수'를 쌍떡잎식물 '토마토'로 바꾼다(해바라기·강낭콩·토마토).
  - 교사 ③: 별 2는 완전한 줄(세포부터 개체까지 5장) 하나 이상, 별 3은 동물의 완전한 줄과 식물의 완전한 줄을 각각 내야 받는다. 별 1의 조건과 턴 수 같은 수치는 규칙 모듈 시뮬레이션 뒤 정한다. 별과 따로 두는 필수 확인 활동은 만들지 않는다.
  - 총괄 ④ (과학 사실이라 교사 확인 없이): 줄 전체 제약을 하나 더한다. '심장 근육 세포가 든 줄의 기관은 심장이어야 한다.' 근육 조직→위 관계는 참이므로 유지한다. 줄을 새로 놓을 때와 놓인 줄에 패를 붙일 때 모두, 붙인 뒤의 줄 전체를 다시 검사한다.
  - 총괄 ⑤: relationError는 실제로 거짓인 연결만 센다(예: 심장 근육 세포→신경 조직). 참이지만 이 게임이 다루지 않는 연결(신경 조직→심장 등)은 새 신호 `outOfScope`로 분리해 '이 게임에서 다루지 않는 연결'로 안내하고 오개념 집계에서 뺀다. 이웃 쌍은 관계표에 있으나 줄 전체 제약을 어긴 시도는 `lineConflict`로 센다.

  - 별 기준을 두고 README에 '별은 이해를 판단하지 않는다'만 적는 안. 비교 없이 최고 별을 받는 규칙이 그대로 남아 AGENTS.md의 원칙과 맞지 않는다.

### D-056 구성 단계 루미큐브의 목표는 완전한 줄 만들기(손패 비우기를 별 조건에서 뺌), 줄은 단계 순서로 자동 정렬, 틀린 시도는 턴을 쓰지 않음
- 날짜 · 상태: 2026-10-06 · 채택(교사 결정)
- 맥락: 1단계 규칙 모듈(GPT-6-Astra 구현)을 Claude Opus가 독립 검토했다. 판 재배치 금지(D-051) 아래에서 손패 비우기를 별의 전제로 두면 패를 모아 두었다 한꺼번에 놓는 전략만 이긴다. 예산 없는 정확 풀이기의 이론상 최대치는 32턴에서 손패 비우기 91.5%·별 3 75.1%였지만, '놓을 수 있으면 다 놓는' 학생형 전략은 32턴에서 별 0이 97.7%였다(1,000판). 남는 패의 47%가 핵심 개념 패인 조직계·기관계였다.
- 결정: ① 손패 비우기를 별 조건에서 빼고, 동물·식물의 완전한 줄(세포→…→개체)을 만드는 것을 목표로 한다. 두 계의 완전한 줄을 모두 내면 판이 끝나고, 아니면 턴 상한에서 끝난다. 별 3은 두 계의 완전한 줄, 별 2는 한 계의 완전한 줄이다. 별 1의 조건(묶음·부분 사슬 등)과 턴 상한은 시뮬레이션으로 정한다(Opus 시뮬레이션: 학생형이 완전한 줄만 놓을 때 상한 14·18·20·24턴에서 별 3이 33.7·57.2·70.3·87.6%). ② 줄을 낼 때 화면이 고른 패를 단계 순서로 자동 정렬하고 '이룬다' 관계만 판정한다. 누른 순서는 오개념으로 세지 않는다. ③ 틀린 줄·묶음은 턴을 쓰지 않고 까닭을 알려 다시 시도하게 한다(오개념 신호는 기록).
- 근거: 별이 가르치려는 개념(동물·식물의 구성 단계 사슬과 3·4번 칸 차이)을 직접 반영하고, 평범한 플레이로도 도달할 수 있어야 한다. 단계 숫자가 패에 보이므로 순서 맞추기는 개념 이해의 근거가 되지 못하고 조작 실수만 오개념으로 쌓는다.
- 검토한 대안: 지금 규칙에 '모아 두었다 놓아도 된다' 안내만 더하기(32턴 별 3 38.5%·별 0 48.4%), 판 재배치 허용(원작 규칙, 휴대폰 조작이 복잡해지고 D-051을 바꿈), 시작 손패 20장·이름당 1장·완전한 줄 보장 배분(학생형 성공률이 거의 오르지 않음). 누른 순서대로 판정(orderError), 틀린 시도에 턴 소모.
- 영향: 규칙 모듈·Node 테스트 수정(Astra), 묶음은 별 1이나 점수로만 반영되므로 B 수준 활동의 비중이 줄어든다—결과 화면 문항·설명해 보기로 보완. 설계 문서의 규칙·별 기준·오개념 신호(orderError 제거) 갱신. 같은 검토의 다른 지적(판정 분류 순서, 테스트 공백, API 모호함)도 함께 고친다.
- 관련: D-051, D-052, D-055

### D-057 루미큐브 난도는 줄을 노리는 학생 기준(20턴), 한 턴에 틀린 시도 3번이면 패 한 장을 뽑고 턴을 넘김
- 날짜 · 상태: 2026-10-06 · 채택(교사 결정)
- 맥락: D-056에 따라 GPT-6-Astra가 규칙 모듈을 고쳤다(별 3 = 두 계의 완전한 줄, 별 2 = 한 계, 별 1 = 두 계 각각 4장 이상 부분 사슬, 잠정 상한 20턴, 점수 완전한 줄 계마다 100·부분 사슬 3장 10·4장 20·묶음 2). 1,000판 시뮬레이션(20턴)에서 완전한 줄을 노리는 학생형은 별 3 70.3%·별 0 0.5%였으나, 놓을 수 있으면 다 놓는 학생형은 별 3 5.1%였다(묶음에 줄에 필요한 패를 씀). 틀린 시도가 턴을 쓰지 않아 한 턴에 300번 찍는 경우 별 2 이상이 25.9%였다(한 턴 1번 찍기는 0%).
- 결정: ① 난도는 '완전한 줄을 노리는 학생' 기준으로 맞추고 상한 20턴을 유지한다. 화면에 목표(동물·식물의 완전한 줄 만들기)를 늘 보인다. ② 한 턴에 틀린 시도가 3번이면 패를 한 장 뽑고 다음 턴으로 넘어간다(앞의 두 번은 까닭을 보고 다시 시도).
- 근거: 별은 목표로 제시한 활동(완전한 줄)을 해낸 정도를 나타내야 하고, 묶음을 먼저 내 줄에 필요한 패를 쓰는 것은 그 자체로 배울 거리다. 시도 상한은 학습을 위한 재시도를 남기면서 찍기를 막는다.
- 검토한 대안: 다 놓는 학생도 별을 받게 패 배분이나 묶음 되돌리기를 더하는 안(규칙이 복잡해지고 재설계 필요), 찍기를 그대로 두고 기록만 하는 안.
- 영향: 규칙 모듈·Node 테스트에 시도 상한을 넣고 인수 시뮬레이션을 '줄을 노리는 학생' 기준으로 고친다. 화면은 목표 문구와 남은 시도 수를 보인다.
- 관련: D-055, D-056

- 날짜 · 상태: 2026-10-06 · 채택(교사 결정)
