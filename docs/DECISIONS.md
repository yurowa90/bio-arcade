# 결정 기록 (Decision Log)

이 저장소에서 내린 결정을 기록한 순서대로 번호를 매겨 적는다(나중에 기록한 결정은 날짜가 앞설 수 있다). 코드와 커밋은 '무엇을 바꿨는지'를 남기지만, '왜 그렇게 정했고 무엇을 버렸는지'는 여기에만 남는다.

## 쓰는 법

- 새 결정은 맨 아래에 다음 번호로 추가한다. 번호는 다시 쓰지 않는다.
- 새 항목을 쓰면 색인 표에도 한 줄 넣는다. 색인의 '결정' 칸과 본문 제목은 같은 문구로 쓴다.
- 결정을 뒤집을 때는 원래 항목을 지우지 않는다. 상태를 `대체됨(D-0NN)`으로 바꾸고 새 항목을 쓴다.
- 근거가 기록에서 확인되지 않고 추론한 것이면 `(추정)`이라고 적는다.
- 교사의 판단을 기다리는 일은 결정이 아니므로 `docs/PROGRESS.md`의 미결 사항(M번호)에 둔다. 진행 문서의 항목은 T·M 고정 번호로 가리킨다.

항목 형식:

```
### D-0NN 제목
- 날짜 · 상태: YYYY-MM-DD · 채택 | 대체됨(D-0NN) | 철회
- 맥락: 무엇이 문제였나
- 결정: 무엇으로 정했나
- 근거: 왜 그렇게 정했나(검증 수치가 있으면 함께)
- 검토한 대안: 버린 안과 버린 까닭
- 영향: 바뀌는 파일·테스트, 뒤따라 지켜야 할 것
- 관련: 커밋, 파일, 문서
```

### D-005 광합성 기공 전환 무료, 별 6·9·12
- 날짜 · 상태: 2026-10-02 · 채택
- 맥락: 별 3 칭찬은 '밤에 기공을 닫아 물을 아꼈다'인데, 실제 규칙에서는 밤에도 기공을 열어 두는 쪽이 유리했다(밤 열림 최대 녹말 11, 닫힘 9). 닫았다 다시 여는 데 행동 두 번이 들고, 열어 둘 때 손해는 물 1뿐이었다.
- 결정: 기공 열기·닫기는 턴을 쓰지 않는다. 가뭄 동안 물 흡수는 0, 처음 물은 3, 별 기준은 녹말 6·9·12(승리 6). 별 3 칭찬은 밤 턴에 기공이 실제로 닫혔을 때만 나온다.

- 검토한 대안: 밤 손실 +1·+2, 새벽 자동 열림. 열림·닫힘 격차가 0~1이거나 생물학적 근거가 약해 버렸다.
- 영향: `tests/quest-logic.js`에 '밤에 연 수열 최대 < 별 3 기준' 단언. 규칙을 바꾸면 `node tests/quest-tune-photo.js`로 다시 확인한다.

### D-008 소화 별 3은 쓸개즙 유화 뒤 분해
- 날짜 · 상태: 2026-10-02 · 채택
- 맥락: 쓸개즙 없이도 별 3이 나와, 쓸개즙의 역할을 묻는 '설명해 보기'와 규칙이 반대 메시지를 줬다(의견 갈림 지적).
- 결정: 쓸개즙으로 지방을 유화한 뒤 이자액으로 분해해야 별 3. 쓸개즙 없이 이자액을 두 번 써도 이기지만 별은 2개까지다. 질문은 '꼭 필요한'에서 '돕는 까닭'으로 바꿨다.
- 근거: 쓸개즙은 소화 효소가 없고 유화로 지방 소화를 돕는다. 쓸개즙 없이도 분해는 되므로 '꼭 필요'는 틀린 표현이다. 전수 탐색 21,888 수열에서 쓸개즙 없이 이긴 수열의 별 3은 0개.
- 검토한 대안: 유화 전에 이자액을 한 번이라도 쓰면 감점하는 엄격한 안. 교사 판단으로 넘겼다(M3).
- 영향: 이자액→쓸개즙→이자액 순서도 별 3이며 테스트가 이를 단언한다.
- 관련: 5c38040(질문 문구), 130277a(유화·별 조건)

### D-009 관찰 칩 숨김, 질문 종류를 정답과 분리
- 날짜 · 상태: 2026-10-02 · 채택
- 맥락: 관찰 전 카드가 무리·분류·역할 칩을 보여 정답이 드러났다. 칩을 숨긴 뒤에도 질문 종류가 생물 무리에 따라 정해져(균류에게만 '어느 무리', 식물에게만 '양분') 종류만 보고 답을 짐작할 수 있었다.
- 결정: 관찰 전에는 서식지·활동 시간 칩만 보인다. 무리·역할 질문은 모든 생물에, 척추 질문은 동물에게만 낸다. 생물별 질문은 `data.js`의 `ask`로 정한다. 느타리는 무리를 맞히면 역할 질문으로 이어진다.
- 근거: 배정 전수 탐색(3^13×2^5)으로 네 풀(숲·습지×낮·밤)마다 세 질문 종류가 모두 나오고 종류마다 정답이 갈리는 배정을 골랐다. 최다 정답 비율 50~60%. 배정 전수 탐색과 대안 비교는 당시 실행 기록이며 스크립트는 저장소에 없다. 현재 배정의 분포는 `tests/quest-logic.js`가 단언한다.
- 검토한 대안: 풀마다 세 종류가 다 나와야 한다는 조건을 빼면 최다 비율을 50%까지 낮출 수 있지만, 숲 풀에 역할 질문이 사라져 버렸다.
- 영향: 분해자가 첫 질문의 정답인 생물은 없다(M1).
- 관련: 5c38040, 130277a
