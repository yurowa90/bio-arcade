# 시각 원칙: A '빛나는 과학 도감'

> 상태: 확정 사항은 교사 결정(D-062·D-068)이고, '제안'으로 표시한 값은 혈액 순환 일주에 처음 적용하며 정한 것이다. 제안은 다음 게임(멘델의 텃밭, 구성 단계 잇기)에 적용할 때 확인하고 확정한다. 시안 원본은 저장소 밖 `~/.cache/bio-arcade-work/style/style-directions.html`의 A 방향이다.

## 확정 사항

- **방향.** 밝은 바탕에 또렷한 외곽선, 넓은 평면 채색에 어두운 한 면만 더한 명암. 그림 자체에는 그림자를 넣지 않는다. 배경·생물 그림·카드·버튼·점수판을 한 스타일로 맞춘다(D-062).
- **그림은 코드로 그린 SVG.** 이미지 생성 도구의 그림은 쓰지 않는다. 원작 게임의 이름·그림·캐릭터·상징은 쓰지 않는다(D-026).
- **학습 대상 그림은 교과서 전형을 따른다.** 심장·혈관, 세포·조직·기관, 완두 형질처럼 학생이 배우는 대상은 교과서 모식도의 관례(마주 본 심장, 좌심실 벽이 가장 두꺼움 등)를 따르고, 게임에 넣기 전에 과학 교차 검토(`/cross-review`)를 거친다. 판의 길에 맞추려고 바꾼 곳은 README '게임이 단순화한 것'에 적는다. 혈액 순환 판의 대동맥을 좌심실 옆으로 낸 것이 그 예다(D-068 ④).
- **혈액 색.** 산소가 많은 혈액 선홍색 `#e53935`, 적은 혈액 검붉은색 `#6d1b2b`. 파랑으로 칠하지 않는다(D-042). 두 색의 대비는 2.70:1이라 색만으로 구분하지 않고 O₂ 점 개수와 흐름 화살표를 함께 둔다.
- **난도 이름.** 모든 게임에서 지금 판은 '기본 판', 그 위는 '도전 1·도전 2'다. 난도에 '단계'라는 말을 쓰지 않는다. 구성 단계 잇기의 '생물의 구성 단계'와 헷갈리지 않게 하려는 것이다(D-068 ③).
- **문장.** 화면 문장은 해라체로 쓰고, 학생에게 시키는 문장만 '-세요'로 쓴다(D-059). 점수와 별은 놀이 기록이며 성취수준이 아니다(D-026).

## 색

| 토큰 | 값 | 쓰임 | 대비(WCAG) |
|---|---|---|---|
| `--bg` | `#e8f2e8` | 쪽 바탕 | 본문 10.23:1, 보조 5.26:1 |
| `--panel` | `#fffdf5` | 카드·패널·보기 버튼·패 | 본문 11.53:1, 보조 5.93:1 |
| `--board` | `#f7fbf1` | 게임 판 바탕 | 본문 11.20:1, 보조 5.76:1 |
| `--ink` | `#203d39` | 본문 글자 | 위 세 바탕 모두 10:1 이상 |
| `--muted` | `#536760` | 보조 글자(단위, 설명 한 줄) | 위 세 바탕 모두 5.2:1 이상 |
| `--accent` | `#246844` | 기본 버튼 채움, 선택 표시 | 버튼 글자 `#fffdf5`와 6.57:1 |
| `--line-strong` | `#47645a` | 보기 버튼·패널 테두리 | 패널과 6.37:1 |
| `--line` | `#bbcbbb` | 장식 구분선 | 패널과 1.67:1. 의미 있는 경계에는 쓰지 않는다 |
| `--outline` | `#35504a` | 그림 외곽선 | 판과 8.35:1, 심장 벽색과 3.93:1 |

- 글자는 바탕과 4.5:1 이상, 그림의 의미 있는 경계(방 테두리, 관 외곽선)는 3:1 이상으로 한다.
- 혈액 색 위의 이름은 흰 글자에 어두운 외곽선(`paint-order: stroke`)을 둘러 쓴다. 흰 글자와 선홍색의 대비가 4.23:1이라 외곽선 없이 쓰지 않는다. 밝은 칸 위 이름은 `--ink` 글자로 쓰고, 그물선처럼 글자를 지나는 선이 있으면 바탕색 테두리(약 5px)를 둘러 선을 끊는다. 흰 점·흰 글자를 밝은 바탕에 두지 않는다(크림 바탕과 1.02:1).
- 회색·투명도만으로 상태(잠김, 비활성)를 나타내지 않는다. 글자나 아이콘을 함께 둔다.
- 제안: 두 순환의 소속 표시는 색상이 분명히 다른 두 계열로 하고 범례에 글자를 함께 둔다. 혈액 순환 일주는 폐순환 `#245b79`(파랑), 온몸순환 `#774912`(갈색)을 방 테두리와 범례 글자에 썼다. 판 바탕과 7.03·7.29:1, 심장 벽색과 3.31·3.44:1이다. 두 색의 밝기 대비는 1.04:1이라 흑백 인쇄에서는 구분되지 않으므로 글자 범례를 빼지 않는다. 시안처럼 거의 검정에 가까운 두 색은 화면에서도 구별이 어렵다.
- 제안: '지금 칸'·'묻는 칸' 표시는 순환 색과 다른 금색 `#e0a412`로 한다(묻는 칸은 점선). 금색은 그림 외곽선과 3.96:1이지만 심장 벽색과는 1.01:1, 판 바탕과는 2.11:1이라 금색만으로는 경계가 흐려진다. 그래서 어두운 밑선(`--outline`, 폭 7.4)을 깔고 그 위에 금색(3.4)을 얹은 두 색 띠로 그린다. 바깥쪽에 어두운 띠가 약 2 SVG 단위 남는다.

## 글자 위계

| 층 | 크기 | 굵기 | 쓰임 |
|---|---|---|---|
| 제목 | 24px | 750 | 화면 제목, 결과 카드 제목 |
| 주요 수치 | 27px(넓은 점수판), 20~22px(44px 머리띠 안) | 750, 고정폭 숫자 | 점수, 결과 점수 |
| 본문 | 15px | 400, 강조 650 | 안내, 해설, 버튼 |
| 보조 | 12px | 400 | 단위, 내 최고 기록, 짧은 설명 |
| 판 안 글자 | 16 판 단위(실제 12px 이상) | 700 | 칸 이름, 범례 |

- 굵기는 제목과 수치에 모은다. 설명문을 굵게 쓰지 않는다.
- 입력칸 글자는 16px 이상이다(iOS 확대 방지, `docs/DEVELOPMENT.md` 함정 6).
- 패 이름처럼 작은 그림에 붙는 이름은 10~11px까지 허용하되, 학생이 꼭 읽어야 하는 글자는 12px 이상으로 둔다.

## 선·모서리·그림자

- 그림 외곽선 2.3, 내부선 1.8(SVG 단위). 선 끝과 꺾임은 둥글게 한다.
- 모서리: 버튼 10px, 패널·카드 12px, 패 7px, 점수판 5px, 장면(판·텃밭) 16px.
- 그림자: 버튼 `0 3px 0 #3c674520`, 패 `0 2px 0 #3c674525`만 쓴다. 패널과 그림에는 그림자를 두지 않는다.

## 그림 규칙

- 넓은 평면 채색 + 어두운 한 면. 반사광(`shine`)은 밝은 선 하나로 한정한다.
- 조직의 반복 구조(세포 줄, 무늬)를 생략하지 않는다. 작은 패에서도 실루엣과 핵이 남도록 그린다.
- 그림은 실제 쓰는 크기로 줄여서 알아보는지 확인한다. 혈액 순환 판의 다리 근육처럼 판 크기에서 알아보기 어려우면 다시 그린다.
- 크기 비율, 판막 잎 수, 세부 구조처럼 생략한 것은 그림 목록과 README에 적는다.
- 공용 그림은 `shared/art/symbols.js`의 기호(`window.ArcadeArt`, id·클래스 접두사 `art-`)로 두고, 한 게임에서만 쓰는 판 그림은 그 게임 폴더에 둔다(예: `games/circulation/board.js`). 기호 안에 한 게임 전용 색을 박지 않고 CSS 변수로 받는다. 기호는 숨은 스프라이트로 한 번만 넣고 외부 파일을 요청하지 않는다.
- 그림 위에 이름판·점·관·말을 얹을 때 학습 대상의 특징을 가리지 않는다. 혈액 순환 판에서 좌심실 이름판과 대동맥 관이 좌심실 바깥벽을 덮어, 그려 둔 벽 두께 순서가 화면에서 사라진 일이 있었다. 얹은 것까지 넣고 '보이는 모습'으로 다시 잰다.

## 아이콘 규칙

- 이모지와 문자 글리프(유니코드 주사위 ⚀~⚅, ← 같은 화살표 글자를 아이콘으로 쓰는 것)를 쓰지 않고 같은 선 스타일의 SVG를 쓴다. 작은 아이폰에서 글리프가 다르게 보이는 문제도 함께 없앤다(D-049).
- 24px 격자, 1.8px 선, 둥근 선 끝. 기능 아이콘(뒤로, 도움말, 닫기, 별, 확인, 잠금, 주사위, 시계)은 채우지 않고 글자색(`currentColor`)을 따른다. 생물 그림만 채색한다.
- 아이콘 옆에 글자가 있으면 아이콘은 `aria-hidden`이다. 아이콘만 있는 버튼은 `aria-label`을 단다.
- 학습 표기인 글자 기호(빈 이름표 □, 경로의 →, 범례의 ●·○)는 아이콘이 아니므로 그대로 쓴다.

## 부품

- **기본 버튼.** `--accent` 채움, `--accent-ink` 글자, 모서리 10px, 버튼 그림자. 한 화면에 하나(다음으로 넘어가는 행동).
- **보조 버튼(보기).** `--panel` 바탕, `--line-strong` 테두리, `--ink` 글자. 고른 정답은 초록 테두리·옅은 초록, 오답은 붉은 테두리·옅은 분홍(공통 `.btn.right`·`.btn.wrong`).
- **패널.** `--panel` 바탕, `--line` 테두리, 모서리 12px, 그림자 없음. 강조할 내용은 한 줄로, 자세한 설명은 펼친 뒤 읽게 한다.
- **점수판.** 정돈된 정보 띠: 점수(주요 수치), 진행(바퀴·날·턴), 내 최고 기록(보조)을 한 띠에 둔다. 비교는 내 최고 기록과만 한다(D-063). 숫자는 고정폭으로 바꿔 자리가 흔들리지 않게 한다. 연속 정답(콤보)과 최고 기록 갱신 반응은 게임별 규칙과 공통 기록 층이 정해지면 같은 띠에 더한다(D-063~D-065).
- **결과 카드.** 별 → 이번 점수 → 내 최고 기록과 비교 → 다음 행동(다시 하기, 다음 도전) → '게임 점수와 별은 성취수준이 아니다' 한 줄. 갱신했을 때만 확인 띠를 보인다.
- 움직임은 짧게(0.6초 안팎) 하고, 동작 줄이기에서는 최종 값을 바로 보인다.

## 적용과 공통으로 올릴 것

혈액 순환 일주에 처음 적용했다(D-068). 공통 파일(`shared/arcade.css`)은 다른 세션이 맡고 있어, 혈액 순환 일주는 A 토큰과 부품 스타일을 그 쪽 안에 두었다. 멘델의 텃밭에 적용하기 전에 토큰(`:root` 변수)·버튼·패널·점수판 스타일을 공통 파일로 올린다.
