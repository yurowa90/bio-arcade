이 쪽에는 결정으로 정해진 것만 적는다. 바꾸려면 결정(D번호)을 새로 남긴다. 2026-10-09 교사가 시안을 보고 설계를 승인했다(아래 '교사 선택'). 세부 설계는 그 아래 '세부 설계'에 있다.

- **핵심 경험**(D-066, 교사 방향): 더 크고 복잡한 가계도에서 여러 단서를 조합하고 논리적으로 사고해서 지뢰(반드시 보인자)를 찾는다. 한 단서만으로는 풀리지 않는다.
- **학습 목표**: [9과21-05]의 '가계도를 분석하여 사람의 유전 현상을 설명'. 상염색체 열성 유전과 X 염색체 열성 유전(적록 색맹)에서, 표현형과 부모·자녀 관계로부터 대립유전자가 어디서 왔는지 따라가고, '보인자일 수도 있다'와 '반드시 보인자다'를 구별한다. A 수준의 설명은 결과 화면의 '설명해 보기'로 한다.
- **유지할 것**: 정답은 해결기가 가능한 유전자형 조합을 모두 따져 계산한다(사람이 정하지 않는다). 확정할 수 없는 사람에게 표시하면 지뢰다. 발현자 안내는 성별·유전 방식으로 나눈다(D-014). 화면 용어는 중학교 교과서 용어(보인자, 대립유전자, 열성, 적록 색맹)만 쓰고 동형 접합·이형 접합 같은 생명과학Ⅰ 용어는 쓰지 않는다(D-013). 판정 뒤 '표시 지우기'는 꺼지고 같은 문제를 다시 풀지 않는다(D-061). 지금 4문제 판(이제 이름은 '기본 판', D-068 ③)은 처음부터 늘 열려 있고, 별 기준과 기록은 그대로다(D-064 ①).
- **이번 범위**(D-064 ③·D-065·D-066, 총괄 조건):
  - 난도 이름은 '기본 판·도전 1·도전 2'다. '단계'라는 낱말로 난도를 부르지 않는다(D-068 ③). 기본 판 안의 '1~4단계' 표시는 문제 순서라 지금 화면대로 두고, 도전 판의 문제 순서는 '2/4'처럼 숫자로만 쓴다.
  - 기본 판 위에 도전 1·2를 쌓는다. 도전 1은 처음부터 열리고, 도전 2는 도전 1로 연다. 재도전은 제한하지 않는다. 해금은 더 어려운 판을 여는 것일 뿐 성취수준이 아니다.
  - 도전 문제는 판마다 새로 만든다. 같은 문제를 반복해 최고 기록이 오르지 않게 한다.

  - 혼인으로 들어온 사람은 기본적으로 보인자가 아니다. 색맹 여성은 논리에 꼭 필요할 때만 드물게 둔다. 단순화하면 README의 '게임이 단순화한 것'에 적는다.
  - 그래픽은 A '빛나는 과학 도감'(밝은 바탕, 또렷한 외곽선, 평면 채색에 한 단계 명암)을 따른다(D-068 ①). 시각 원칙 1쪽(`docs/design/visual-style.md`)이 나오기 전에는 그래픽 시안 A 방향의 색·선·글자 위계를 따른다.
  - 점수판·해금 화면의 모양은 시각 원칙과 공통 기록 층(T12)에 맞춘다. 이번에는 기록 데이터와 최소한의 고르기 화면만 만든다.

## 세부 설계 (2026-10-09 교사 승인)

처음에는 총괄과 AI의 제안으로 썼고, 교사가 시안을 보고 승인했다. 위 '교사 선택'과 다른 부분은 교사 선택을 따른다.

### 1. 참고 문항: 수능·학력평가의 가계도 문항에서 빌리는 것과 바꾸는 것

교사는 수능·학력평가·모의고사의 가계도 문항을 참고로 들었다. 이 문항들은 생명과학Ⅰ 범위라 용어와 일부 자료가 중학교 범위를 넘는다. 그래서 **문항의 짜임(가계도 + 일부 구성원의 추가 자료 + 조건문 → 여러 단계 추론)은 빌리고, 용어와 자료는 중학교 교과서 범위로 바꾼다.**

| 생명과학Ⅰ 문항의 요소 | 이 게임에서 | 까닭 |
|---|---|---|
| 구성원 번호 1~10 | 사람마다 번호를 붙인다(도전 판). 판정 근거도 번호로 말한다 | '왼쪽에서 두 번째 딸' 같은 이름보다 짧고 정확하다 |
| 일부 구성원의 DNA 상대량 표 | **유전자 검사 카드**: "4번에게는 열성 대립유전자(a)가 없다." 있음·없음만 쓴다 | DNA 상대량은 생명과학Ⅰ 내용이다. 지금 게임도 '유전자 검사가 필요'라는 말을 이미 쓴다 |
| 조건문 "1과 2 중 이형 접합인 사람은 1명이다" | **개수 카드**: "4번, 12번 중 보인자는 1명이다." | '이형 접합' 대신 '보인자'. 지뢰찾기의 숫자와 같은 구실을 한다 |
| (가)의 유전자가 상염색체에 있는지 X 염색체에 있는지 판단 | 도전 2 후보 (가): 유전 방식을 숨기고 먼저 판단하게 한다 | 쓰는 사실은 중학교 내용이다(아들의 X 염색체는 어머니에게서 온다, 딸이 색맹이면 아버지도 색맹이다). 판단하는 일 자체는 중학교 교과서보다 한 걸음 더 나간다 → 교사 선택 |
| 두 형질 (가)·(나)를 함께 다룸 | 쓰지 않는다 | 한 형질만으로도 여러 단계 추론을 만들 수 있고, 두 형질은 화면과 부담이 두 배다 |
| 우성·열성 판별 | 쓰지 않는다. 형질은 늘 열성이라고 알려 준다 | 우성 형질에는 '보인자'가 없어 게임의 중심 개념이 사라진다 |
| 자녀가 태어날 때 발현할 확률 | 지금처럼 결과 화면의 '한 번 더 떠올리기' 문항에만 둔다 | 놀이의 중심을 '반드시 보인자 찾기'에 둔다 |

### 2. 단서 종류

| 단서 | 화면 문장(시안 A 기준) | 무엇을 할 수 있게 하나 |
|---|---|---|
| 가계도 | 성별(□ 남, ○ 여), 발현(검게 칠함), 부모·자녀선, 번호 | 기본 추론. 발현 자녀 → 부모가 a를 가짐, 발현 부모 → 자녀가 a를 가짐, 아들의 X는 어머니에게서 옴 |
| 유전자 검사 카드 | "① 4번에게는 열성 대립유전자(a)가 없다." | 대립유전자가 올 수 있는 길을 하나 끊는다. 상염색체 유전에서 '이 a는 어머니에게서 왔다'를 정하게 해 준다 |
| 개수 카드 | "② 4번, 12번 중 보인자는 1명이다." | 다른 단서로 한쪽을 지우면 나머지가 정해진다 |

- 검사 카드는 **정상인 사람에게 '없다'만** 쓴다. '있다'는 그 사람이 바로 보인자라는 답을 알려 주기 때문이다. X 염색체 유전에서 정상 남성을 검사하는 카드는 도전 2의 유전 방식 판단에만 쓴다(정상 남성에게 a가 없다는 것은 X 염색체 유전이면 당연하고, 상염색체 유전이면 정보가 된다).
- 개수 카드는 숫자가 0이거나, 보인자가 될 수 있는 사람 수보다 작을 때만 쓴다. 같으면 카드가 곧 답이다.
- 단서 카드는 문제마다 0~2장이다. **준 카드는 모두 정답에 쓰인다**(카드를 빼면 반드시 보인자가 줄어든다).
- 상염색체 문제에서는 검사 카드가 사슬을 잇는 데 주로 쓰인다. X 염색체 문제는 가계도 안에서도 사슬이 생긴다(색맹 손자 → 어머니는 보인자 → 외할아버지가 정상이므로 외할머니도 보인자).

### 3. 판 구성 (D-064 ①, 이름은 D-068 ③)

| 판 | 내용 | 문제 | 열림 |
|---|---|---|---|
| 기본 판 | 지금 그대로(고정 4문제, 화면의 '1~4단계' 순서 표시 포함, 별·설명해 보기·기록 유지). 최고 기록 갱신 반응은 첫 판에만(D-064 ③) | 고정 | 늘 열림 |
| 도전 1 · 단서 조합 | 3세대, 10~13명, 번호, 단서 카드 0~2장. 한 묶음 4문제(상염색체 2, X 염색체 2, 순서 무작위) | 판마다 새로 생성 | 처음부터 열림(D-065) |
| 도전 2 · 유전 방식 추리 | 유전 방식을 숨기고 판정 전에 먼저 고르게 한다. 단서 카드 1~2장. 한 묶음 4문제(답이 상염색체 2, X 염색체 2, 순서 무작위). 남은 보인자 수는 숨긴다 | 판마다 새로 생성 | 도전 1 한 묶음에서 지뢰 0, 놓친 보인자 합계 1명 이하 |

- 한 묶음 안의 문제는 서로 다른 모양이다(번호·좌우만 바꾼 같은 문제를 내지 않는다).
- 놀이 점수(데이터만): 문제를 완전 해결(놓침 0, 지뢰 0)하면 +10, 아니면 0. 연속 완전 해결 수를 콤보로 기록한다. 별은 지금 별 규칙(맞힘·놓침·잘못 표시)을 묶음 합계에 그대로 쓴다(D-064 ⑤: 별 기준은 그대로, 놀이 점수는 따로).
- 찍기로 문턱을 넘을 확률: 문제마다 5% 이하이므로 한 묶음 4문제를 모두 맞힐 확률은 0.05⁴ ≈ 0.0006% 이하다. 고른 문턱(지뢰 0, 놓침 1명 이하)으로도 0.01% 아래로 어림한다. 구현 뒤 생성 문제로 다시 계산한다.

#### 3-1. 도전 2에서 유전 방식 판단을 돕는 사실 다시 보이기(교사 선택 2)

판단에 쓰는 사실은 중학교에서 배운 것이지만, '이 사실로 유전 방식을 가린다'는 쓰임은 처음 만난다. 그래서 세 곳에서 다시 보여 준다. 사실은 처음 세 줄로 정했다가, Opus 검토(2026-10-09)에서 생성 문제의 판단이 '남성은 보인자가 될 수 없다'와 '발현한 부모 → 자녀'에도 기대는 것이 드러나 네 줄로 넓혔다. 재검토(2026-10-10)에서 '발현자가 모두 남성이면 X'라는 지름길이 99% 맞는 것이 드러났다. 원인은 X 가정을 반박하는 길이 발현 여성뿐이었던 것이다. 그래서 '정상 아버지의 딸이 가진 a는 어머니에게서 왔다'(사실 2)와 '부모 한 사람에게 a가 없으면 다른 사람에게서 왔다'(사실 3)를 문장에 넣었다. 이렇게 하면 외할머니까지 이어지는 반박도 사실로 설명된다.
- **유전 방식을 가르는 사실**
  1. 아들의 X 염색체는 어머니에게서만 온다. 그래서 X 염색체 열성 형질은 아들이 발현하면 어머니가 a를 가지고, 어머니가 발현하면 아들도 모두 발현한다.
  2. 딸은 아버지와 어머니에게서 X 염색체를 하나씩 받는다. 그래서 X 염색체 열성 형질은 딸이 발현하면 아버지도 발현하고, 아버지가 발현하면 딸은 a를 가지며, 아버지가 정상인 딸에게 a가 있으면 그 a는 어머니에게서 왔다.
  3. 상염색체 유전에서는 아들과 딸 모두 부모에게서 대립유전자를 하나씩 받는다. 그래서 발현한 자녀의 부모는 모두 a를 가지고, 발현한 부모의 자녀는 모두 a를 가지며, 부모 한 사람에게 a가 없으면 자녀의 a는 다른 한 사람에게서 왔다.
  4. 남성은 X 염색체가 하나라 X 염색체 열성 형질의 보인자가 될 수 없다.
- **도전 2 시작 안내**(도전 2 묶음을 시작할 때마다, 짧게): 위 네 줄과 [시작] 단추.
- **문제 화면의 자료 칸**: 유전 방식 고르기 단추 곁에 '판단에 쓰는 사실' 접힘 단추를 둔다. 누르면 네 줄이 펼쳐진다(기본은 접힘, 자료 첫 줄이 첫 화면에 보이게).
- **풀이 보기의 첫 줄들**: 다른 유전 방식의 모순 가운데 가장 짧은 사슬을 보이고, 결론 줄에 그 사슬에 쓰인 사실 번호를 모두 적는다(예: "…모순이다(사실 1·2). 그러므로 상염색체 열성 유전이다."). 가정 속 문장은 '보인자다'로 단정하지 않고 '…a를 가져야 한다'로 쓴다.
- 생성기는 그 가장 짧은 모순 사슬이 사실 1~4와 단서 카드로만 이루어지고 6줄 이하인 문제만 낸다. 겉모양(카드 종류, 검사 대상의 성별, 발현자의 성별, 딸의 비율)만으로 유전 방식을 맞히는 정확도를 테스트로 제한한다(실제 특징인 '발현자가 모두 남성'은 85% 이하, 나머지는 65% 이하).

### 5. 판정 근거: 추론 사슬

생성기와 함께 **추론 엔진**을 만든다. 엔진은 아래 규칙만 써서 사실(누가 a를 가진다, 누가 a를 가지지 않는다)을 하나씩 더한다. 규칙 하나가 판정 근거의 한 줄이 된다. 문제마다 '그 보인자를 정하는 데 쓰인 단계만' 거꾸로 따라가 보여 주므로 뭉뚱그린 문장이 나오지 않는다.

상염색체 열성(A 정상 > a):
- A1 발현한 사람은 aa다. 정상인 사람은 A를 하나 이상 가진다.
- A2 자녀가 발현(aa) → 부모는 각각 a를 가진다.
- A3 부모 한 사람이 발현(aa) → 자녀는 a를 가진다.
- A4 자녀가 a를 가지고 부모 한 사람에게 a가 없음 → 다른 부모가 a를 가진다.
- A5 부모 모두 a가 없음 → 자녀도 a가 없다.
- 결론: 정상인데 a를 가지면 보인자다.

X 염색체 열성(적록 색맹):
- X1 아들이 색맹 → 어머니는 색맹 대립유전자를 가진다(아들의 X 염색체는 어머니에게서만 온다).
- X2 아버지가 색맹 → 딸은 색맹 대립유전자를 가진다.
- X3 딸이 색맹 대립유전자를 가지고 아버지가 정상 → 어머니가 색맹 대립유전자를 가진다.
- X4 딸이 색맹 → 어머니가 색맹 대립유전자를 가진다(아버지도 색맹이어야 한다).
- X5 어머니에게 색맹 대립유전자가 없고 아버지가 정상 → 딸에게도 없다.
- 남성은 X 염색체가 하나라 보인자가 될 수 없다.

카드:
- T 검사 카드 → 그 사람에게 a가 없다.
- C1 개수 카드의 보인자가 이미 k명 정해짐 → 나머지는 보인자가 아니다.
- C2 보인자가 될 수 있는 사람이 k명만 남음 → 그 사람들은 보인자다.

유전 방식 판단(도전 2 (가)): "상염색체 유전이라고 해 보자 → 규칙을 따르다 모순"이 나오면 그 방식이 아니다. 예: "9번이 발현(aa)했으므로 아버지 7번도 a를 가져야 하는데 카드 ①에서 7번에게는 a가 없다. 모순이므로 X 염색체 유전이다."

해결기(`solve`, 모든 유전자형 조합 전수)와 추론 엔진의 관계:
- 엔진이 낸 사실은 해결기의 모든 조합에서 참이어야 한다(엔진이 틀린 말을 하지 않는다).
- 생성기는 **엔진이 해결기의 must를 모두 찾아내는 문제만** 낸다. 그래서 모든 정답에 판정 근거 사슬이 있고, 경우를 나눠 따져야만 풀리는 문제는 나오지 않는다(중학생 범위의 난도를 지킨다).
- 잘못 표시한 사람에게도 근거를 준다: 엔진이 'a가 없다'를 정한 사람은 그 사슬을, 정하지 못한 사람은 "가계도와 단서로는 a가 있는지 정할 수 없다"를 보인다.

### 6. 생성기가 지킬 조건 (`tests/pedigree-logic.js`가 시드 2,000개로 전수 검사)

1. 실제로 가능한 가계도다: 숨은 유전자형을 실제 유전 규칙으로 물려주어 만들고, 해결기가 가능한 조합이 1개 이상임을 확인한다. 카드는 숨은 유전자형에 비추어 참인 것만 낸다.
2. must가 1명 이상이고, 추론 엔진이 must를 모두 찾아낸다.
3. 여러 단서 조합: 문제마다 must 가운데 적어도 한 사람은 사슬 깊이가 2 이상이다(앞 단계에서 정한 사실을 다시 써야 정해진다). 준 카드는 모두 쓰인다.
4. 찍기 5% 이하: 유전 방식을 알고(발현자, X 염색체 유전이면 남성 제외), 검사 카드로 a가 없다고 밝혀진 사람을 빼고, 개수 카드의 산수를 맞추며, 남은 보인자 수 k를 아는 학생이 k명을 고를 때 맞힐 확률이 5% 이하다. 카드 산수만으로(유전 규칙 없이) 확정되는 사람이 없다.
5. 색맹 여성: X 염색체 문제 가운데 색맹 여성이 있는 문제는 10% 이하이고(최종 생성: 도전 1 75/2,000, 도전 2 98/2,000), 있으면 아버지가 발현하고 그 사람이 판정 근거 사슬에 쓰인다.
6. 혼인으로 들어온 사람은 숨은 유전자형을 대부분 정상(AA, 정상 남성)으로 뽑는다. 이들이 must가 되는 비율을 보고한다.
7. 화면 크기: 3세대, 10~13명, 같은 세대 간격 1.25칸(50px) 이상(판정 고리 바깥 반지름 25px이 겹치지 않음), x 0.4~7.4, 번호 글자가 선·기호와 겹치지 않는다, 부부선 사이에 다른 사람이 끼지 않는다, 자녀선끼리 겹치지 않는다.
8. 재현성: 같은 시드·같은 도전·같은 유전 방식이면 같은 문제. 전역 난수·시각을 쓰지 않는다.
9. 기존 `LEVELS` 4개와 `solve()` 결과가 바뀌지 않는다(회귀).
10. 묶음 안 4문제는 모양이 서로 다르다. 문제 모양과 정답 위치가 고르게 퍼진다(정답 무늬 수를 보고).
11. 도전 2 (가): 두 유전 방식 가운데 정확히 하나만 가능하고, 엔진이 다른 하나의 모순을 찾아낸다.

### 7. 화면 (교사 선택: 시안 A '자료형')

공통: 사람 번호, 카드를 누르면 카드가 가리키는 사람이 강조된다, 표시 방식(◐ → ? → 없음)과 발현자 안내는 지금 그대로, 판정 뒤 ✓·✗·! 고리, '풀이 보기'로 사슬을 한 단계씩 본다. 도전 2 (가)는 판정 전에 '상염색체 / X 염색체'를 고른다.

- **고른 안, 시안 A '자료형'**: 가계도 아래에 수능 문항처럼 조건 목록(○ 열성, ○ 유전 방식, ① ② 카드 문장)과 유전자 검사 결과 표를 둔다. 읽는 양이 늘지만 시험 문항과 모양이 같다.
- 버린 안, 시안 B '판 위 표시형': 검사 결과와 개수 카드를 가계도 위 표지로 붙인다. 읽는 양은 적지만 시험 문항 모양과 다르다.
- 그래픽은 A '빛나는 과학 도감'(D-068 ①)이다. 기본 판과 도전 판이 같은 화면 틀을 쓴다. 지뢰찾기 오마주의 구조(남은 수 숫자판, 표시 지우기 단추, 시간)는 남기고 색과 선을 A 방향으로 바꾼다.

판 크기: 360px 너비 viewBox, 3세대 높이 300 안팎. 시안 검사(2026-10-09, Chromium·WebKit × 360×640·390×844·412×915)에서 나온 것과 구현 때 지킬 것:
- 360×640에서 판정 단추가 첫 화면 밖으로 밀렸다(시안 A 161px, B 74px 모자람). 시안은 판정 전 판정 단추를 화면 아래에 붙여(sticky) 고쳤다. 구현도 같게 하고 E2E로 확인한다.
- 풀이 창은 가계도 바로 아래에 둔다. 결과 목록 아래에 두면 휴대폰에서 풀이 문장을 읽을 때 강조된 가계도가 화면 밖에 있다(시안에서 옮겨 고쳤다).
- 360px 폭에서 사람 터치 영역이 42px로 44px에 못 미친다(390px 46px, 412px 49px). 지금 게임과 같은 좌표라 지금 판도 같다(추정, E2E는 390px만 잰다). 구현 때 좁은 화면의 판 여백을 줄여 360px에서도 44px 이상으로 하고 E2E에 360px을 더한다. 시안 B의 표지 터치 영역도 작다(360px 35×28px).
- 이웃한 두 사람을 모두 판정 고리로 표시하면 오른쪽 위 ✓·✗ 기호가 옆 사람의 고리를 침범한다(간격 1.25~1.3칸). 구현 때 기호를 고리 안쪽이나 위로 옮긴다.

### 8. 기록 데이터 (공통 기록 층 T12 계약, 화면 모양은 시각 원칙 뒤)

- `A.finish`에 공통 필드를 넘긴다: `level`(기본 판 0, 도전 1, 도전 2), `cond`(같은 조건끼리 최고 기록을 견줄 짧은 문자열: 도전 1 'mix', 도전 2 'hidden', 기본 판은 넘기지 않음), `playScore`(완전 해결 문제당 10), `maxCombo`(연속 완전 해결 최댓값), `cleared`(도전 판 묶음이 문턱을 넘었을 때만 true), `eligible`(기본 판은 그 기기의 첫 기본 판만 true, 그 뒤는 false — 같은 문제의 반복이므로. 도전 판은 늘 새 문제라 true). T12가 아직 합쳐지지 않아 지금의 `A.finish`는 이 필드를 받지 않으므로, 같은 값을 `detail`에도 남긴다(`detail.kind`='basic'|'challenge', `detail.level` 등). 합칠 때 총괄이 맞춘다.
- 도전 2가 열렸는지는 `A.isUnlocked('pedigree', 2)`가 있으면 그것을, 없으면 기록에서 도전 1 판 가운데 `cleared`(또는 `detail.cleared`)가 true인 판이 있는지로 계산한다.

- 도전 판도 `A.finish`로 기록하고, `detail.challenge`에 다음을 담는다: 도전 번호, 묶음 시드, 문제마다 {시드, 유전 방식, 고른 유전 방식(도전 2 (가)), must 수, 맞힘·놓침·잘못 표시·남성 오표시·'일 수도' 오표시, 걸린 시간, 완전 해결 여부, 사슬 깊이, 쓴 카드 수}, 묶음 합계(완전 해결 수, 지뢰 수, 놀이 점수, 최대 연속), 문턱 통과 여부.
- `shared/`는 고치지 않는다(공통 기록 층은 T12 세션).
- 기본 판의 기록 형식은 바꾸지 않는다. 기존 기록에 가계도 판이 있으면 '첫 판 아님'으로 본다(D-065 총괄 조건).
- 도전 판의 '설명해 보기'는 그 묶음 마지막 문제의 가계도를 축소해 곁에 그리고 묻는다: "반드시 보인자인 사람 한 명을 골라, 두 가지 이상의 단서를 어떻게 이어서 판단했는지 쓰세요."

## 견본 문제 (시안에 쓰는 3개, 전수 검산함)

번호, 성별, 발현은 시안과 같다. 숫자 앞의 [ ]는 부모(아버지, 어머니)다. 검산: 카드를 넣은 전수 해결과 찍기 모형(위 6절 4번)을 임시 스크립트로 돌렸다.

**P1 도전 1 · 상염색체 열성 · 카드 1장**
1세대 1(남, 발현)─2(여), 3(남)─4(여) · 2세대 5(여)[1,2], 6(남)[1,2]─7(여)[3,4], 8(남)[3,4] · 3세대 9(남, 발현)[6,7], 10(여)[6,7]
카드 ① 4번에게는 a가 없다.
must {3, 5, 6, 7}(카드 없으면 {5, 6, 7}), 보인자일 수도 있음 {2, 8, 10}, 찍기 1/35(2.9%).
사슬: 1번 aa → 5·6번 a / 9번 aa → 6·7번 a / 7번 a + 4번 a 없음(①) → 3번 a(깊이 2).

**P2 도전 1 · X 염색체 열성(적록 색맹) · 카드 2장**
1세대 1(남)─2(여), 3(남)─4(여) · 2세대 5(여)[1,2], 6(여)[1,2]─7(남)[3,4], 8(여)[3,4]─9(남, 혼인) · 3세대 10(남, 색맹)[7,6], 11(여)[7,6], 12(여)[9,8], 13(여)[9,8]
카드 ① 8번에게는 색맹 대립유전자가 없다. ② 4번, 12번 중 보인자는 1명이다.
must {2, 4, 6}(카드 없으면 {2, 6}), 보인자일 수도 있음 {5, 11}, 찍기 1/20(5.0%, 경계값).
사슬: 10번 색맹 → 6번 보인자 → 아버지 1번 정상이므로 2번 보인자(깊이 2) / 8번 없음(①) + 9번 정상 → 12번 없음 → ②에서 4번 보인자(깊이 3).

**P3 도전 2 (가) · 유전 방식 숨김 · 카드 1장**
1세대 1(남)─2(여), 3(남)─4(여) · 2세대 5(여)[1,2], 6(여)[1,2]─7(남)[3,4], 8(여)[3,4], 9(여)[3,4] · 3세대 10(남, 발현)[7,6], 11(여)[7,6], 12(남)[7,6]
카드 ① 7번에게는 a가 없다.
상염색체라면 가능한 조합 0개(10번 aa인데 아버지 7번에게 a가 없다 → 모순) → X 염색체 유전. must {2, 6}, 보인자일 수도 있음 {4, 5, 8, 9, 11}, 찍기 1/21(4.8%).

## 단순화(README '게임이 단순화한 것'에 넣을 문안 초안)

- 가계도 지뢰찾기 도전 판의 유전자 검사 카드는 '열성 대립유전자가 있다·없다'만 알려 준다. 실제 유전자 검사는 이보다 많은 정보를 주며, 가족 안에서 누구를 검사할지는 의료진과 함께 정한다.
- 가계도 지뢰찾기 도전 판의 가계도는 문제를 만들려고 보인자와 발현자가 실제보다 자주 나오게 만들었다. 실제로는 상염색체 열성 유전병의 보인자가 집단에 많지 않고, 혼인으로 들어온 사람이 보인자인 경우도 드물다. X 염색체 열성 형질이 나타난 여성은 실제로 드물다(적록 색맹은 남성보다 훨씬 적다). 그래서 아버지가 발현하고 어머니가 a를 가진 경우로만 드물게 넣었다(X 문제의 도전 1 약 4%, 도전 2 약 5%). '발현 여성이 있으면 X 염색체 유전이 아니다'라는 짐작이 늘 맞지 않게 하려는 것이다.
- 가계도 지뢰찾기 도전 판의 개수 카드("○번, ○번 중 보인자는 1명이다")는 퍼즐 장치다. 실제 가계도 조사에서 이런 정보를 얻는 일은 없다.

## 검토한 대안(버린 것)

- 생명과학Ⅰ 문항을 그대로 옮기기(DNA 상대량, 두 형질, 우성·열성 판별): 중학교 용어 규칙(D-013)과 맞지 않고 '보인자 찾기'의 중심이 흐려진다.
- 기본 판을 생성 문제로 바꾸기: 수업에서 같은 4문제로 이야기하고 설명해 보기가 4단계(넷째 문제) 가계도를 쓰므로 그대로 둔다(D-064 ①).
- 4세대 가계도: 360×640 화면에 판·카드·단추가 함께 들어가지 않는다.
- 사람 수만 늘리기(초판): 정답 위치가 고정되거나 찍기가 쉬워지고, 여러 단서를 조합할 일이 생기지 않는다.
- 표현형을 가린 사람(수능의 '발현 여부를 나타내지 않음'): 흥미롭지만 '반드시 보인자'와 '발현자일 수도 있음'이 섞여 표시 규칙이 복잡해진다. 다음 판 후보로 둔다.
