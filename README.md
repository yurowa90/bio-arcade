# 생명 오락실

2000년대 피처폰·스마트폰·PC 명작 게임의 **구조와 조작감만 빌린 오마주** 생명과학 미니게임 모음입니다. 원작의 이름·캐릭터·그림·상징은 쓰지 않습니다.
대상은 중학교 2학년 ~ 고1 통합과학1입니다. 휴대폰·태블릿에 설치형 웹앱(PWA)으로 설치할 수 있고, 설치하면 오프라인에서도 실행됩니다.

## 게임과 성취기준

성취기준·성취수준은 2022 개정 과학과 교육과정(교육부 고시 제2022-33호 [별책 9])과 교육부·평가원 성취수준에서 가져왔습니다.
원본 데이터는 `teacher-essaytest`의 `standards-data.js`이고, 이 오락실이 쓰는 기준만 `shared/standards.js`로 발췌했습니다(PDF 추출 띄어쓰기 오류 보정).

## 기록과 제출

학생이 허브에 학번·이름을 적으면, 게임마다 별·점수·세부 기록·인출 문항 정답 여부·서술 답이 기기에 저장됩니다.
허브의 “요약 복사”나 “JSON 저장”으로 제출합니다. 세부 기록에는 오개념 신호가 들어 있습니다. 예를 들어 염기쌍 팡은 같은 염기끼리 붙이려 한 횟수를, 가계도는 남성을 보인자로 표시한 경우를 남깁니다.

## 검증

```bash
node tests/quest-logic.js            # 탐사대 지도 연결·체육관 규칙
PW=$(npm root -g)/playwright node tests/arcade-e2e.js <스크린샷 폴더>   # 휴대폰 화면 전체 플레이
PW=$(npm root -g)/playwright node tests/quest-e2e.js <스크린샷 폴더>
```

- 멘델: F2 9:3:3:1, 검정 교배 1:1이 통계적으로 나오는지 확인했습니다.
- 가계도: 4단계 모두 해결기의 “확실한 보인자”가 교과서 추론과 일치합니다. X 연관에서는 남성이 보인자로 판정되지 않습니다.
- 혈당: 반응이 늦은 사람을 흉내 낸 조절로 난이도를 맞췄습니다. 기본 모드는 반응만으로 통과하고, 인슐린 저항성 모드는 식사를 미리 대비해야 별 3개가 나옵니다.

## 게임이 단순화한 것 (수업에서 짚을 것)

- 혈당 모델은 게임용입니다. 실제 혈당 조절이나 당뇨병 치료를 흉내 내지 않습니다.
- 에너지 런에서 세포 호흡은 “포도당 1 + 산소 1 → 에너지”로 단순화했습니다. 실제 비율과 다릅니다.
- 멘델의 텃밭의 두 유전자는 서로 다른 염색체에 있다고 가정합니다(독립의 법칙).
- 탐사대의 광합성 체육관은 제한 요인을 min(빛, CO₂, 물)로 단순화했습니다.
