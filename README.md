# 생명 오락실

1990~2010년대 게임기·PC·휴대폰 명작 게임의 **구조와 조작감만 빌린 오마주** 생명과학 미니게임 모음입니다. 원작의 이름·캐릭터·그림·상징은 쓰지 않습니다.
대상은 중학교 2학년 ~ 고1 통합과학1입니다. 휴대폰·태블릿에 설치형 웹앱(PWA)으로 설치할 수 있고, 설치하면 오프라인에서도 실행됩니다.

## 기록과 제출

학생이 허브에 학번·이름을 적으면, 게임마다 별·점수·세부 기록·인출 문항 정답 여부·서술 답이 기기에 저장됩니다.
허브의 “요약 복사”나 “JSON 저장”으로 제출합니다. 요약에는 판마다 쓴 서술 답이 판 번호와 함께 모두 들어가고, 생명 탐사대는 체육관별 배지 별이 들어갑니다. 세부 기록에는 오개념 신호가 들어 있습니다. 예를 들어 염기쌍 팡은 염기를 같은 염기 옆으로 옮긴 무효 이동 횟수를, 가계도는 적록 색맹 단계(3·4단계)에서 남성을 보인자로 표시한 횟수를 남깁니다.

기록은 학생별로 나뉘지 않고 기기 하나에 한 사람 몫만 저장됩니다. 여러 학생이 한 기기를 돌려 쓰면, 제출한 뒤 허브의 “기록 지우기”로 학번·이름과 모든 기록(생명 탐사대 저장 포함)을 지우고 넘기게 하세요. 기록이 남은 기기에서 이미 적혀 있던 학번·이름을 다른 값으로 바꾸기 시작하면 허브가 앞 학생의 기록을 지울지 묻습니다. 비어 있던 칸을 채울 때는 묻지 않지만, 앞 기록에 학번·이름이 하나도 없으면 주인을 알 수 없으므로 칸을 채우기 시작할 때 묻습니다. 지우는 일은 그 기기 안에서만 일어나고, 기록은 기기 밖으로 보내지 않습니다.

```bash
node tests/quest-logic.js            # 탐사대 지도 연결·체육관 규칙

PW=$(npm root -g)/playwright node tests/quest-e2e.js <스크린샷 폴더>
```

- 멘델: F2 9:3:3:1, 검정 교배 1:1이 통계적으로 나오는지 확인했습니다.
- 가계도: 4단계 모두 해결기의 “확실한 보인자”가 교과서 추론과 일치합니다. X 연관에서는 남성이 보인자로 판정되지 않습니다.
- 혈당: 반응이 늦은 사람을 흉내 낸 조절로 난이도를 맞췄습니다. 기본 모드는 반응만으로 별 2~3개가 나옵니다. 인슐린 저항성 모드는 같은 조절로도 목표 범위를 벗어나기 쉬워서, 늦게 반응하면 별 1개에 그칩니다.

## 게임이 단순화한 것 (수업에서 짚을 것)

- 혈당 모델은 게임용입니다. 실제 혈당 조절이나 당뇨병 치료를 흉내 내지 않습니다.
- 혈당 지키기의 70~180 mg/dL은 당뇨병 환자가 연속 혈당 측정으로 혈당을 관리할 때 쓰는 **목표 범위**입니다(이 범위에 머문 시간의 비율이 TIR). 건강한 사람의 혈당은 공복 때 100 mg/dL 아래, 식후에도 대개 140 mg/dL 아래에서 유지됩니다. “180까지 정상”으로 기억하지 않게 짚어 주세요.
- 에너지 런에서 세포 호흡은 “영양소 1 + 산소 1 → 에너지”로 단순화했습니다. 실제 비율과 다릅니다.
- 에너지 런의 구간 순서(소장→폐→근육→콩팥)는 실제 혈액 순환 경로가 아닙니다. 심장을 생략했고, 세포에 물질을 전하는 곳도 근육·콩팥 구간만으로 줄였습니다. 실제로는 온몸 곳곳의 조직에서 모세 혈관의 혈액과 조직 세포 사이에 물질 교환이 일어납니다.
- 에너지 런에서는 아미노산을 쓰면 곧바로 요소가 생기는 것으로 단순화했습니다. 실제로는 아미노산이 분해될 때 생긴 암모니아가 간에서 요소로 바뀝니다.
- 멘델의 텃밭의 두 유전자는 서로 다른 염색체에 있다고 가정합니다(독립의 법칙).
- 탐사대의 광합성 체육관은 제한 요인을 min(빛, CO₂, 물)로 단순화했습니다.
- 탐사대 도감에는 식물·동물·균류만 나옵니다. 관찰 문항은 무리(식물·균류·동물), 양분을 얻는 방법(생산자·소비자·분해자), 척추동물 여부(동물만) 세 가지이고, 생물마다 어느 문항을 낼지는 `games/quest/js/data.js`의 `ask`로 정합니다. 질문 종류만 보고 답을 짐작하지 못하게 종류마다 정답이 갈리도록 배정했습니다. 9과02-04의 5계 전체(원핵생물계·원생생물계 포함)와 종·분류 단계는 다루지 않으니 수업에서 보충하세요. 생산자·소비자·분해자는 통합과학2의 생태계 구성 요소(10통과2-02-01)와 이어지는 내용입니다.
- 탐사대 소화 체육관에서 별 3개는 쓸개즙으로 지방을 유화한 뒤 이자액으로 분해해야 받습니다. 쓸개즙 없이도 이자액을 두 번 쓰면 지방이 분해되어 이길 수 있지만 별은 2개까지입니다. 쓸개즙은 소화 효소가 없고 지방의 소화를 돕는다는 점을 짚기 위한 규칙입니다.
- 멘델의 텃밭에서 추론을 틀리면 그 완두와 같은 교배에서 나온 다른 완두는 추론할 수 없고, 검정 교배로만 유전자형 카드를 받습니다. 정답이 공개된 뒤 같은 유전자형의 완두로 다시 푸는 것을 막기 위한 규칙입니다.

## 로컬 작업 + GPT 교차 검증 (선택)

`.claude/agents/gpt-reviewer.md`는 Claude Code 서브에이전트가 OpenAI Codex CLI(`codex exec`)를 **읽기 전용**으로 불러 과학 내용과 성취기준 대응을 교차 검증하게 하는 설정입니다.
쓰려면 로컬에 Codex CLI를 설치하고(`npm install -g @openai/codex`), `codex login`으로 로그인하세요. ChatGPT 맥 앱을 쓰고 있다면 앱에 들어 있는 `/Applications/ChatGPT.app/Contents/Resources/codex-cli/bin/codex`를 그대로 써도 됩니다. 서브에이전트는 `codex`가 PATH에 없으면 이 경로를 씁니다. API 키는 대화창이나 저장소에 넣지 마세요.
서브에이전트는 검토할 발췌를 셸 인자로 넘기지 않습니다. 코드 발췌에 든 백틱·`${…}`가 셸에서 실행되거나 바뀌기 때문입니다. 지시문과 발췌를 임시 파일에 쓰고 `codex exec --sandbox read-only - < 임시파일`처럼 표준 입력으로 넘깁니다.
Claude Code 서브에이전트는 Claude 모델만 쓸 수 있으므로, GPT는 “모델”이 아니라 서브에이전트가 부르는 “도구”로 연결됩니다.
